# Internationalization

English (`en`) and Spanish (`es`) are provided by `src/i18n`. `I18nProvider` is mounted inside `AppShell`, persists `tqb-locale`, and synchronizes `<html lang>`.

UI strings live in centralized dictionaries. Educational entries remain canonical in `src/content/catalog.ts`; `src/content/localization.ts` supplies locale-specific presentation. Equations and the quant engine are language-neutral.

Do not branch on locale in quant modules. Add visible UI copy to the dictionary, add content translations through `localizeEntry`, and test persistence after reload on desktop and mobile.
