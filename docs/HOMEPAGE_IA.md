# Homepage information architecture

The homepage is a compact operating surface, not a campaign hero. Its order is: product thesis and three actions; source-aware market pulse; Learn and Analytics cores; public read-only prediction markets; concept and deterministic intelligence; Desk note.

Learn and Markets remain first-level navigation. Analytics bridges educational models to deterministic calculations. Intelligence bridges displayed observations to transparent metrics. Bateman is a 64px thematic guide with typed UI states; the former large homepage portrait was removed. Rich character animation is intentionally deferred to the existing animation plan.
