# AI privacy

Do not send secrets, client positions, personal information or confidential market data to the assistant. The default local router makes no remote AI call. When Cloudflare Workers AI is enabled, prompts and the minimum necessary page context leave the application boundary; server credentials never reach the browser.

The platform does not intentionally persist assistant questions. Provider logging and retention are governed by the configured provider contract. Production activation requires a privacy notice, retention review, abuse controls and a data-processing assessment.
