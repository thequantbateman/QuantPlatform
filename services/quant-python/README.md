# Optional future quant service

This folder is documentation-only and is not required by the web MVP. A future FastAPI service can use NumPy, SciPy, pandas and QuantLib for Heston/SABR calibration, large Monte Carlo, PDE, local volatility, portfolio analytics and real instrument curve calibration.

Keep endpoints typed and versioned, include convention metadata in every request, and expose health/readiness separately. The web application must retain local analytical fallbacks.
